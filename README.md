# «Точка перехода» — онлайн-игра

Игра работает в двух режимах: локально на одном устройстве и в онлайн-комнате через Supabase Realtime. Локальный режим не требует сервера и сохраняет партию в браузере.

## Как запустить

Откройте проект через любой локальный статический сервер или опубликуйте содержимое корня репозитория на GitHub Pages. Для локальной проверки в Windows можно запустить `preview-server.ps1`, затем открыть `http://127.0.0.1:4173/`.

## Инструкция ведущей

1. Выберите «Играть на этом устройстве», добавьте от одной до шести участниц и назначьте каждой уникальную фишку.
2. Нажмите «Бросить кубик». Фишка переместится, а поверх поля откроется карточка.
3. После обсуждения нажмите «Подтвердить и продолжить». Следующий ход автоматически перейдёт к следующей незавершившей путь участнице.
4. Жетоны и кристаллы добавляются и применяются кнопками `+` и `−` в карточке участницы. Остаток не может стать отрицательным.
5. Заполняйте «Карту перехода» в правой панели. «Печать / PDF» открывает системную печать для выбранной участницы.
6. «Отменить» возвращает состояние до последнего игрового действия. Ручное исправление позиции находится в «Инструментах ведущей» и записывается в журнал.
7. Игра автоматически сохраняется после каждого действия. При следующем открытии выберите «Продолжить игру».
8. Для резервной копии используйте «Экспорт JSON», а для восстановления — «Импорт JSON».

## Реализовано

- поле на 75 ячеек и фишки поверх исходного PNG;
- точные интеграции 9, 24, 39, 54 и финал на 75;
- семь колод по 24 карточки без повторов до исчерпания;
- спокойная анимация кубика и защита от двойного броска;
- 1–6 участниц, автоматический и ручной выбор следующего хода;
- отдельные жетоны и кристаллы, журнал действий и Undo;
- локальное сохранение, экспорт и импорт JSON;
- заполняемая и печатная карта перехода;
- адаптивная вёрстка и скрытый режим калибровки `?calibrate=1`.

## Онлайн-комнаты

Перед первой проверкой выполните целиком `supabase/migrations/001_multiplayer_rooms.sql` в Supabase SQL Editor. Миграция включает RLS, RPC-функции и Realtime-публикацию. Затем ведущая создаёт комнату с шестизначным кодом формата `TP-000000`, отправляет ссылку, ждёт участниц и запускает игру.

Общее состояние партии хранится отдельно от карт перехода. Участница читает и редактирует только свою карту; ведущая видит карты всех участниц. Игровые действия, состав комнаты и карты синхронизируются автоматически. Публичный ключ Supabase находится в клиенте намеренно; защита данных обеспечивается RLS, прямые записи в таблицы закрыты.
